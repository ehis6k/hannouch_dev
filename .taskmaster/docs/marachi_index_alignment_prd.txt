Repository Planning Graph (RPG) - Marachi Design Alignment PRD

This PRD defines the design and structural changes required to align the Hannouch storefront with the Marachi-inspired "Quiet Luxury" reference. The Marachi reference is image-only (no video). The current Hannouch build (Tasks 1–14) provides the foundation: design tokens, header, footer, hero section, editorial-split, product grid, cart drawer, and PDP. This document specifies the deltas—section-by-section and component-by-component—so the theme visually and behaviorally mimics the Marachi inspiration (image-led, no video) while reusing existing Hannouch sections where possible.

<overview>
## Goal
Transform the current Hannouch homepage and key pages so they mirror the Marachi reference: image-led hero (minimal or no text overlay), "Shop By Look" portrait swatch strip, full-body product grid with optional quick-add, editorial splits with strong lifestyle imagery, full-width lifestyle blocks, optional architectural/brand section, and a footer with newsletter (bottom-border input + dark button). All within the existing Quiet Luxury token system.

## Current State (Hannouch)
- Header: Logo left, nav center (SHOP, THE EDIT, ABOUT, CONTACT), SEARCH / ACCOUNT / CART right. White bar, dark text.
- Hero: Grey placeholder with text overlay "RAMADAN 2026" and "SHOP NOW", plus faint geometric line art in background.
- Editorial split 1: Left = placeholder (beige + line-art city skyline). Right = "THE CITY EDIT", body copy, "EXPLORE THE COLLECTION".
- Product grid: "NEW ARRIVALS", 4-column grid, placeholder t-shirt images, title + price (e.g. "TOP OF ORGANIC COTTON", "1200 AED").
- Editorial split 2: Left = "CRAFTED TO LAST", lorem body, "READ MORE". Right = same placeholder line-art.
- Newsletter: "NEWSLETTER", "Exclusive offers...", ENTER YOUR EMAIL, SUBSCRIBE button.
- Footer: SOCIAL, ABOUT, SHOP, HELP, LEGAL columns; copyright; payment icons; currency selector.

## Target State (Marachi Reference)
- Hero: Full-width lifestyle photograph (e.g. model on sofa, textured wall). No large text overlay; optional subtle logo/wordmark overlay.
- Shop By Look: Horizontal strip of 4+ portrait-oriented images (e.g. hijab/look close-ups) with small uppercase labels (MOKA, OLIVE, NUDE, ONYX). Clean, minimal, white/off-white background.
- Product grid: Full-body garment shots (abayas/dresses) on clean studio background. Product title + price below. Optional "Quick Add" or similar below.
- Editorial split: Left = text (eyebrow, heading, body, CTA with arrow). Right = large lifestyle image (e.g. portrait with dove).
- Full-width lifestyle blocks: One or more full-bleed image sections (two models on sofa; single model; etc.) with optional logo watermark.
- Architectural / brand: Two-column image grid (e.g. showroom, staircase) with small uppercase labels and short copy.
- Footer: Newsletter with bottom-border-only email input and dark "SUBSCRIBE" button; multi-column nav (SHOP, ABOUT, HELP, LEGAL); social icons; bottom bar with copyright, payment icons, currency.

## Success Criteria
- Homepage structure and visual hierarchy match Marachi reference when using equivalent content (images, copy).
- Hero can be configured as image-led with no or minimal text overlay.
- "Shop By Look" (portrait swatch strip) exists as a section or block.
- Product cards support consistent full-body/lifestyle imagery styling; optional quick-add where desired.
- Editorial splits and full-width lifestyle sections present strong imagery without overlay controls.
- Footer newsletter and button styling match reference (underline input, dark button).
- All changes use existing design tokens (typography, color, spacing) and do not break existing functionality.
</overview>

## Capability Tree (Marachi-Alignment)

<constraints-and-notes>
## Constraints
- Reuse existing Hannouch design tokens (--font-heading, --font-body, --color-base-text, --color-base-bg, --spacing-*, etc.). No new color system.
- Do not remove or break existing hero, editorial-split, main-collection, or product-information behavior; only add settings and optional UI (e.g. minimal text mode, logo overlay). Marachi alignment uses image-only hero (no video).
- Shop By Look is block-based (image + label + link per block); no dependency on dynamic "looks" or metaobjects unless later specified.

## Out of Scope (for this PRD)
- Video on hero or lifestyle sections (Marachi reference is image-only).
- Dynamic "looks" from metaobjects (Shop By Look uses static blocks only).
- Changing collection or PDP logic beyond optional overlay styling.
- Translation of all new strings (can be added to locales in a follow-up).
</constraints-and-notes>
